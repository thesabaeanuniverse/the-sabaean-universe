## HCM-364 — The Horn Celestial Matrix

HCM-364 is a formal research framework organized as **13 Houses × 7 Gates × 4 Elements = 364 coordinates**. It is designed to separate mathematical structure, interpretation, and historical evidence so that proposed Sabaean-Horn celestial and calendrical relationships can be tested independently.
