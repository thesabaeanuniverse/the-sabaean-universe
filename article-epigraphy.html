Reading the Stones: An Evidence-First Epigraphy Method

The archive begins with the photograph, not with a reconstructed sentence. That simple rule prevents decorative pseudo-script from becoming confused with ancient evidence.

Step 1: Preserve the source image

Keep the original photograph unchanged in the archive whenever possible. Cropped or color-corrected versions can be used for presentation, but the unmodified source should remain available for comparison.

Step 2: Separate reading from restoration

Visible characters, damaged characters, restored readings, transliteration, and translation should not be collapsed into one line without explanation. Each stage introduces a different level of inference.

Step 3: Record provenance

Each inscription entry should eventually include findspot, present location if known, publication reference, object type, material, approximate date, script, language, and bibliographic history.

Step 4: Label uncertainty

If a reading is disputed, the website should show competing readings or mark the uncertain portion rather than forcing a single confident answer.

Visual rule across all projects: authentic supplied inscription image → verified published inscription → no inscription. Generated imitation script is not used as a substitute.
